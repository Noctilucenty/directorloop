# DirectorLoop

Give DirectorLoop a short video and tell it what the video is supposed to accomplish. It watches the
draft, tests whether the intended message comes through, diagnoses why it fails, chooses the smallest
useful repair, renders a new version, tests it again against the same frozen checks, and remembers
what the experiment taught it.

Built at CoreWeave Hacks (Agent Loops), September 12-13 2026. Work in progress; see `docs/` for the
specification, API contract, and status documents as they land. `AGENTS.md` holds the working rules.
